## 실습 내용

- 간단 회원가입과 로그인 기능 추가
- 회원정보, 메뉴정보, 주문내역 및 결재정보는 db에 저장 처리
- SQLAlchemy ORM 사용 CRUD 스키마 구현, 모델 서비스 구현

## 구현 체크리스트

### 1. 회원가입 / 로그인
- [x] 간단 회원가입 기능 (`POST /auth/signup`)
- [x] 간단 로그인 기능 + JWT 토큰 발급 (`POST /auth/login`)
- [x] 비밀번호 해싱(bcrypt) 저장 및 검증

### 2. DB 저장 처리 (SQLAlchemy ORM)
- [x] 회원정보 저장 (`users` 테이블 / `User` 모델)
- [x] 메뉴정보 저장 (`menus` 테이블 / `Menu` 모델)
- [x] 주문내역 저장 (`orders` + `order_items` 테이블 / `Order`·`OrderItem` 모델)
- [x] 결재정보 저장 (`payments` 테이블 / `Payment` 모델)

### 3. CRUD 스키마 구현 (Pydantic)
- [x] 회원 스키마 (생성/응답/토큰)
- [x] 메뉴 스키마 (생성/수정/응답)
- [x] 주문 스키마 (생성/응답, 주문 상세 포함)
- [x] 결제 스키마 (생성/응답)

### 4. 모델 서비스 구현 (service layer)
- [x] `user_service` (회원 조회/가입/인증)
- [x] `menu_service` (메뉴 CRUD)
- [x] `order_service` (주문 생성/조회, 재고·금액 계산)
- [x] `payment_service` (결제 생성/조회, 주문 상태 갱신)

### 5. API 라우터
- [x] 메뉴 API (`/menus`)
- [x] 주문 API (`/orders`)
- [x] 결제 API (`/payments`)

### 6. 동작 검증
- [x] 앱 임포트 및 테이블 자동 생성 확인
- [x] SQLite 기반 엔드투엔드 시나리오(가입→로그인→메뉴→주문→결제) 통과

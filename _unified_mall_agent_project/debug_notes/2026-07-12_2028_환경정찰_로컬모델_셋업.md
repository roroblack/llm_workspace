## 실행 전략 (OpenAI 호환 로컬 서버)

llama-cpp-python은 OpenAI 호환 서버를 제공한다:
```bash
python -m llama_cpp.server --model "<GGUF 경로>" --host 127.0.0.1 --port 8000 --n_ctx 4096
```
→ 엔드포인트 `http://127.0.0.1:8000/v1` (OpenAI SDK `base_url`로 접속 가능)

## 통합 앱 반영 방침

- `core/config.py`에 프로바이더 스위치: `LLM_PROVIDER = local | openai | gemini`
- `local`이면 OpenAI SDK를 `base_url=http://127.0.0.1:8000/v1`, `api_key="not-needed"`, `model=gemma`로 사용
- 개발/빌드 전 과정은 `LLM_PROVIDER=local` → **외부 토큰 0 소모**
- Phase 1~2는 LLM 호출이 없으므로 서버 미기동. **Phase 3(에이전트)부터 로컬 서버 기동** 필요.
- 최종 완료 후에만 `.env`에 실제 키 넣고 `LLM_PROVIDER=openai|gemini`로 짧은 스모크 테스트(토큰 최소).

## 주의 (성능)

- CPU 추론 5GB 모델이라 응답이 느릴 수 있음(수십 초/요청 가능). 테스트는 짧은 프롬프트·낮은 max_tokens로.
- ReAct 다단계 루프는 로컬 모델에서 오래 걸릴 수 있으니 max_steps를 작게(2~3) 두고 검증.

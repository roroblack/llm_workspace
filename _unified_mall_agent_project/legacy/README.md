# legacy/ — 대체·폐기 코드 보존소

이 폴더는 통합 작업 중 **대체되거나 폐기되는 코드·문서를 보존**하는 곳이다 (RULE.md 4절).

## 규칙

1. 기존 코드를 대체/삭제하기 **직전에** 이곳으로 복사한다.
2. 원본 위치를 알 수 있게 경로 구조를 유지한다:
   ```
   legacy/<원본프로젝트명>/<원본 상대경로>
   예: legacy/react_tools_agent_fastapi_project/app/services/vector_db.py
   ```
3. 각 이관 건은 reports/ 리포트에 "무엇을, 왜 legacy로 보냈는지" 기록한다.
4. legacy/ 안의 코드는 실행 대상이 아니다. import 하지 않는다.

## 워크스페이스 원본 프로젝트에 대하여

`llm_workspace/` 루트의 기존 28개 프로젝트 폴더 자체는 이곳으로 옮기지 않고 제자리에 보존한다
(보존/삭제/아카이브 여부는 Phase 7에서 사용자가 결정 — 계획서 5절).
이 폴더에는 통합 프로젝트 내부에서 교체된 코드만 들어온다.

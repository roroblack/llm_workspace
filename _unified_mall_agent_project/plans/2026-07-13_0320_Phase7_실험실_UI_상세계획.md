## 3. 설계
### experiments.py
- `count_tokens(text)` — tiktoken cl100k_base (결정론, API 무관). 학습용 참고치.
- `token_compare(ko_text, en_text)` — {ko_tokens, en_tokens, ratio}. 한국어가 토큰 더 씀 시연.
- `estimate_cost(prompt_tokens, output_tokens, model)` — config PRICE_TABLE(1M토큰당 USD) 기반 비용. 미등록 모델→ConfigError.
- `basic_call(prompt, temperature, max_tokens, chat=None)` / `role_call(prompt, system, chat=None)` — chat 주입.
- `diversity(prompt, n, chat=None)` — n회 호출 → 고유 답변 수(set). n 범위 검증.

### usecase.py (prompt_factory, PDF3)
- `build_usecase_prompt(task_type, text, target_lang=None)` — 요약/번역/이메일/코드/문제생성 별 프롬프트(순수 빌더).
- `run_usecase(task_type, text, chat=None)` — 빌더+실행. 미지원 task_type→ValidationErr.

### static UI
- index.html: 채팅창 + 설정패널(max_steps) + 전송. app.js: fetch `/api/agent/chat`, 답변·steps(thought/action/observation) 렌더. 멀티턴은 화면 누적.
- main.py: `app.mount("/static", StaticFiles(...))`, `GET /` → FileResponse(index.html).

### 마무리
- README.md: 목적·구조·실행법(로컬 Gemma 서버·uvicorn·pytest)·엔드포인트·레거시 관계.
- 레거시 28개 폴더: 보존(사용자 결정 사항) — 삭제 안 함, README에 관계만 명시.

## 1. 목표
의도분류 + 감성분석(실 KoELECTRA) + 상품추천(임베딩 코사인). 에이전트/라우터에 연결.

## 2. 설계 결정 (기록)
- **감성 = 로컬 `monologg/koelectra-base-finetuned-nsmc`** (NSMC 파인튜닝 실모델, HF캐시, 토큰0). transformers pipeline. 학습 성과(Bert_sentiment) 재사용 = 실제 KoELECTRA.
- **의도 = 규칙기반 경량 분류** (키워드). 레거시 PyTorch MLP(시작시 학습)는 이식성·재현성 위해 규칙기반으로 대체(YAGNI). 2차 학습형은 별도 계획.
- **추천 = ko-sroberta 임베딩 코사인** (Phase 5 임베딩 재사용). music_recommend의 감성벡터→코사인 top_k를 상품 도메인으로 전환.

## 3. 산출 파일
```
app/ml/
├── __init__.py
├── intent.py       # classify_intent(text) 규칙기반 → {intent, confidence, matched}
├── sentiment.py    # analyze_sentiment(text) KoELECTRA pipeline(lazy 캐시) → {label, score}
└── recommend.py    # recommend_products(query, top_k) 상품명 임베딩 코사인 top_k
app/routers/nlp.py  # /api/nlp/intent, /api/nlp/sentiment, /api/nlp/recommend
tests/test_intent.py, test_sentiment.py, test_recommend.py
```

## 4. 설계 상세
### intent.py (규칙기반, 결정론)
- 의도: 주문/추천/조회/불만/칭찬/인사/기타
- 키워드 사전 매칭 → 최다 매칭 의도. 매칭 0이면 '기타'. confidence=매칭수 기반.

### sentiment.py (KoELECTRA)
- `analyze_sentiment(text)`: transformers `pipeline("text-classification", model=config.SENTIMENT_MODEL)` lazy 로드·캐시. 라벨 매핑(LABEL_0=부정/LABEL_1=긍정 또는 모델 라벨). {label:긍정/부정, score}
- 모델명 config화(SENTIMENT_MODEL). 빈 입력 ValidationErr.

### recommend.py
- `recommend_products(db, query, top_k=3)`: 상품 카탈로그 로드 → 상품명 임베딩(ko-sroberta) + query 임베딩 → 코사인 유사도 top_k. {results:[{code,name,score}]}
- 임베딩은 Phase 5 get_embeddings 재사용. 상품 임베딩은 요청마다 재계산(카탈로그 5개라 경량) 또는 캐시.

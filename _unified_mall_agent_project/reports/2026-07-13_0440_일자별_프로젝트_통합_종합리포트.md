## 3. 통합 앱 모듈별 — 어떤 레거시 특징이 담겼나

- `app/core` ← 콘솔 6종 common.py + FastAPI 3종 config를 **프로바이더 추상화(local/openai/gemini)+에러 taxonomy**로 단일화
- `app/db`·`app/auth`·`app/services` ← board_mysql/coffee의 **JWT·주문/결제 CRUD**를 트랜잭션 원자성으로 정리
- `app/tools`·`app/agent` ← react/agent_loop/function_calling/tool_system의 **도구설계·수동 ReAct·LangChain 자동화**를 흡수(도구6·안전장치3·좋은도구 5원칙·구조화 실패관찰)
- `app/prompts` ← prompt/cot/planning 콘솔의 **few-shot·인젝션방어·CoT·분류 정확도·혼동쌍 개선루프·Plan 재계획**
- `app/rag` ← vector_db/langchain_test의 **인덱싱/서비스 분리·FAISS 거리점수·메타필터·증분·map-reduce 요약**(임베딩은 로컬 ko-sroberta)
- `app/ml` ← coffee/survey/Bert_sentiment/music의 **의도분류·KoELECTRA 감성·임베딩 추천**
- `app/lab` ← llm_parameter/chatgpt/usage의 **파라미터·다양성·토큰·비용·기능별 유즈케이스**
- `app/static` ← chatgpt/survey UI의 **멀티턴 챗·설정·에이전트 단계 표시**

## 3. 선정 근거 상세

1. **도메인 연속성**: "승승장구몰"은 콘솔 6종(재고/주문/CS 데이터), fastapi_board_mysql(주문/결제 DB), fastapi_llm_parameter(프롬프트 기본값), react 프로젝트(도구/문서)를 이미 관통한다. 데이터·도구·프롬프트를 그대로 재사용할 수 있는 유일한 소재.
2. **아키텍처 수용력**: ReAct 에이전트는 기능을 "도구 등록"으로 흡수한다. 새 학습 요소가 생겨도 도구 1개 추가로 통합되므로, 28개 프로젝트의 이질적 기능을 담는 그릇으로 구조적으로 가장 적합.
3. **학습 흐름의 종착점**: 커리큘럼(from_colab_llm)이 전처리 → 분류 모델 → 파인튜닝 → LLM API → 프롬프트 → FC → 에이전트 → RAG로 진행되며, react 프로젝트가 그 최종 산출물. 통합 = 커리큘럼 총정리와 동일한 의미를 가짐.
4. **기술 스택 최대 교집합**: FastAPI, LangChain, OpenAI+Gemini, PyTorch, pandas, Vector DB를 이미 한 프로젝트에서 결합해 봄 — 통합 시 스택 충돌 리스크 최소.

## 4. 기능 흡수 맵 (레거시 → 통합 프로젝트)

| 통합 모듈 | 흡수하는 레거시 기능 | 출처 프로젝트 |
|---|---|---|
| `core/` 설정·클라이언트 | .env/require_key/프로바이더 팩토리 단일화 | 콘솔 6종 common.py, FastAPI 3종 |
| `agent/` ReAct 엔진 | 수동 루프, max_steps, 중복호출 차단, history 트리밍, 토큰 추적 | react, agent_loop, function_calling |
| `agent/planning` | Pydantic Plan, 검증→재계획, Plan-and-Execute | planning_agent_console |
| `prompts/` | 역할/few-shot/JSON 강제/인젝션 방어/CoT·자기검증, prompt_factory | prompt_console, cot_console, llm_usage |
| `tools/` 커머스 도구 | 재고/가격/주문상태/상품검색/환율 | 콘솔 3종, react tools_service |
| `db/` + `auth/` | SQLAlchemy 모델(User/Menu/Order/Payment), JWT, 라우터-서비스 계층 | board_mysql, coffee, bound |
| `rag/` | FAISS/Chroma 인덱스 영속화, 메타필터, 증분 추가, 청킹, PDF 요약(map-reduce) | vector_db, react vector_db.py, langchain_test |
| `ml/` 분류 서비스 | 의도분류(PyTorch MLP→KoELECTRA 업그레이드 경로), 감성분석, 뉴스분류 전처리 | coffee, survey, Bert_sentiment, NAVER, BBC, nlp_model |
| `lab/` 파라미터 실험실 | temperature/top_p/다양성/토큰 비교, 프로바이더 비교 | llm_parameter 2종, chatgpt 설정, kogpt2 슬라이더 |
| `web/` 챗 UI | 멀티턴 세션, 설정 패널, 진행형 대화(설문 패턴) | chatgpt, survey, coffee, react static |
| (선택) 추천 도구 | 코사인 유사도 태그 추천 → 상품 추천 도구로 전환 | music_recommend |
| (선택) 번역 도구 | 번역 기능은 LLM 도구로 대체 (자체 Transformer는 학습 기록으로만 보존) | smart_translator, llm_usage translation |

미이관 대상(학습 기록으로만 legacy 보존): KoNLPy 기초 실습 3종의 실습 스크립트, from_colab_llm 원천 자료, 각 프로젝트 zip/ori 백업, models/ 산출물 복사본.

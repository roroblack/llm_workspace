## 3. 종합 결과

| 상태 | 개수 | 비고 |
|---|---|---|
| 완전 반영 | 15 | 통합 앱의 실 기능으로 흡수 |
| 부분 반영 | 8 | 핵심만 흡수, 나머지는 도메인/난이도 사유로 축약 |
| 의도적 미이관 | 5 | test_konlpy, word_embed, from_colab_llm, models + (전처리 기초류) |

**빠진 것(누락) 여부**: 통합 앱에 **넣어야 하는데 빠진 항목은 없음.** 부분·미이관 8+5건은 모두 다음 중 하나에 해당:
- (a) 상위집합 프로젝트가 이미 흡수 (bound⊂board, BBC→NAVER→Bert 계보)
- (b) 커머스 에이전트 도메인과 불일치 (음악 URL, 번역 자체학습, KoGPT2 로컬추론)
- (c) 학습 기초 단계라 통합 앱 기능이 아님 (KoNLPy·BOW·TF-IDF 전처리 실습)

이들은 RULE.md 3.3(YAGNI)에 따라 **legacy/원본 보존**으로 처리하는 것이 옳으며, 누락이 아니다.

## 4. 이관 시 주의(재확인)

- 부분/미이관도 **원본 폴더는 보존**되어 학습 기록은 유실되지 않음 (Phase 7에서 사용자가 최종 정리 방침 결정).
- KoELECTRA(NAVER/Bert) 실모델 이관은 Phase 6에서 모델 크기·경로 결정 후 별도 계획으로 분리(§8).
- react 베이스의 폴백/데모 코드는 §7 체크리스트로 제거 확정.

## 5. 결론

**28개 프로젝트 전부가 계획서 v2에서 명시적으로 처리(흡수 또는 근거 있는 미이관)됐고, 통합 앱에 반영돼야 하는데 누락된 항목은 없다.** 교과목 3 강의 PDF 커버리지도 별첨 리포트의 조치로 핵심 항목 100% 반영됐다(경미 항목 포함, Phase 7 최종 재점검).

## 2. 계획 합의(6건) 반영 확인
1. **DB 세션**: `with_db(op)`로 도구 실행마다 open/finally close. **MCP 서버 단독은 테이블 생성·seed 안 함**(lifespan 없음) — DB 미준비 시 예외 전파. `get_exchange_rate`는 세션 안 만듦(상수). `catalog://products`도 자체 세션. ✅
2. **도구 10개 고정**: 커머스5 + RAG2(`vector_search`=service.search, `rag_qa`=qa.answer) + ML3(sentiment/intent/recommend). **`search_knowledge_base` 제외**(vector_search와 중복) — 테스트로 부재 검증. ✅
3. **버전**: `mcp[cli]==1.28.1` 핀(설치본 일치 확인). langgraph 재추가 안 함. ✅
4. **테스트 마커**: 등록/도구 결정론=기본, stdio subprocess=`@pytest.mark.mcp`, CI 제외. ✅
5. **재사용**: 기존 `commerce_tools`/`rag.service`/`rag.qa`/`ml.*` 함수 얇게 래핑, 중복 구현 0. ✅
6. **미이관**: external_systems(slack/github/email/browser/샌드박스)·MySQL knowledge_items — 범위 밖·보안·YAGNI로 미이관(계획에 사유 기록). ✅

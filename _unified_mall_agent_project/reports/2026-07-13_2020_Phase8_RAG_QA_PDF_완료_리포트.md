## 3. RULE / Codex 합의 준수
- PDF 파싱실패→InfraError(폴백 금지), LLM 연결실패→InfraError
- 무근거 고정답변("제공된 문서에서 찾을 수 없습니다")은 **폴백 아님**(정상 도메인 응답)
- sources는 **서버가 결정**(모델 생성 아님), (source,page) 중복제거·순서유지, TXT page=null, **PDF page 1-based**
- 프롬프트에 문서 내 지시 무시(인젝션 방어) 명시

## 4.5 Codex 구현 점검 반영 (조건부 미완 → 보완)
Codex 지적 반영:
1. (높음) **인덱스가 문서 변경 미감지**(임베딩 모델만 확인) → build_index가 `.docs_manifest`(txt/pdf 파일·크기 지문) 기록, `index_is_current`가 문서 지문까지 비교 → PDF 추가 시 자동 재빌드. 테스트 `test_index_is_current_detects_doc_change`
2. (중간) **qa LLM 오류 처리 확대**: APIConnectionError만 잡던 것 → +APITimeoutError/APIError(InfraError), **빈 응답→LLMOutputError**(빈답 정상반환 금지). 테스트 `test_empty_llm_response_raises_llm_output_error`
3. (중간) **테스트 보강**: 근거있으나 답없음→NO_ANSWER 통과, **검색 본문이 프롬프트에 전달**되는지 검증
4. (중간) PDF fixture: PDF 없으면 `assert`로 명확 실패

## 4.6 정정 (표현 정확화)
- "환각억제/PDF 근거"는 **로직 검증**(무근거→NO_ANSWER, 프롬프트에 본문 전달) + **라이브 출처 인용**으로 확인. LLM 답변의 사실 정확성까지 자동보장하는 것은 아님.

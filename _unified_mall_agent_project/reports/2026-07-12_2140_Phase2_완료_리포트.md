## 2. RULE 준수
- 하드코딩 없음: SECRET_KEY·DB·모델명 전부 config. 레거시 `getenv(default="change-this")` 미도입.
- 폴백 없음: 인증 실패 401, 권한 위반 403, 재고부족 422, 없는 리소스 404 — 전부 명시적 오류. seed 매칭실패도 조용히 skip 안 하고 InfraError.
- 트랜잭션 원자성: 주문+재고차감+항목 1 commit, 결제+주문PAID 1 commit (예외 시 rollback).

Codex가 인메모리 E2E 독립 재검증(전부 통과) 후 **기능 GO / RULE-done 미완** 판정. 4건 반영:

3. `.env.example`에 `SECRET_KEY`/만료 문서화
4. history/v2 진행표 갱신
→ **테스트 29 → 32개, 전부 pass.** Codex 조건 충족 → Phase 2 done.

## 0. 워크스페이스 총평

- 전체는 하나의 강의 커리큘럼 산출물이다. `from_colab_llm/`(6/24~7/10 일자별 Colab 강의 자료)이 원천이고, 나머지 프로젝트는 이를 PyCharm/실행형 프로젝트로 재구성한 것.
- 학습 흐름: **형태소 전처리 → 워드임베딩 → 딥러닝 분류(RNN/LSTM/CNN) → BERT 파인튜닝 → LLM API/파라미터 → 프롬프트 엔지니어링 → Function Calling → Tool 설계 → Agent Loop → Planning → Vector DB/RAG → ReAct 에이전트 → 웹 서비스(FastAPI/Streamlit)**
- 가상 쇼핑몰 **"승승장구몰"** 도메인이 콘솔 6종, FastAPI 다수, ReAct 프로젝트를 관통하는 공통 소재.
- 중복이 매우 많음: `common.py` 복제 6회 이상, 동일 데이터셋(CSV/PDF) 4개 이상 프로젝트에 중복 보관, 프로젝트 자기 자신의 zip 백업, 폴더 통째 중첩 사본(word_embed 내부) 등.

## 1. 그룹 A — 콘솔 LLM 실습 시리즈 (6종)

모두 "승승장구몰" 소재, `while True` 번호 메뉴 콘솔, **Gemini(주) + OpenAI(보조)** 이중 구성, 거의 동일한 `common.py`(.env 로드, require_key, get_genai_client, LangChain get_chat), API 키 불필요 PyTorch 텐서 데모 1개씩 포함.

| 프로젝트 | 주제 | 핵심 기능 |
|---|---|---|
| `prompt_console_project` | 프롬프트 엔지니어링 | 역할 기반 답변, few-shot 7분류 + 정확도 측정, JSON 강제 출력(response_mime_type), 프롬프트 인젝션 방어(구분자+강화 롤), HTML 강의 파싱 |
| `cot_console_project` | Chain-of-Thought | 직접답변 vs CoT vs 자기검증 3단 파이프라인, 정규식 숫자 추출, Gemini/OpenAI 동일 로직 |
| `function_calling_console_project` | Function Calling | 자동 FC vs 수동 루프 대비, DB_DOWN 장애 시뮬레이션 → 오류를 모델에 되돌려 사과문 생성, 환율+재고 복합 질문 |

## 2. 가장 중요한 누락 5가지 (우선순위)

1. **LangChain 프레임워크 계층 부재** — 강의 후반(PDF5 8강~)의 핵심 "수동 루프로 원리 → LangChain으로 자동화"의 후반부가 계획서에 없었음.
2. **도구 실행 오류 처리**(try/except → 친절 메시지) — PDF6이 "진짜 서비스의 조건"으로 강조.
3. **오분류 혼동쌍 분석 루프**(측정→분석→처방→재측정) — PDF5 7절 핵심 사고방식.
4. **인덱싱/서비스 분리 아키텍처**(build_index/service, 서버기동 1회 로드) — PDF4 최강조.
5. **FAISS 점수=거리(코사인 반대) 주의점** — 구현 시 정렬 버그 유발 지점.

경미: Playground 실습, 비용추정/한↔영 토큰, 기능별 유즈케이스 개별, CoT 끄는 판단·좋은 도구 5원칙, JSON 3방식 구분.

## 2. 구현 요약

### embedding (14강)
- `most_similar(query, docs, k, embeddings=None)`: 임베딩→`top_k_indices`(정규화 코사인)→상위 k `{index,doc,score}`. 빈 query→ValueError.
- `compare_pairs(a, b, unrelated, embeddings=None)`: 유사 쌍 vs 무관 쌍 코사인. `{similar_score, unrelated_score, ok}`.
- `embeddings` 주입 가능(기본 Gemini `get_embeddings("gemini")`). reviews.csv를 rag_qa에서 이관(embedding 프로젝트에 없었음).

### rag_console (13강)
- `chunk_text(text, size=500, overlap=50)`: 직접 구현. **연속 청크가 정확히 overlap 글자 겹침**(`chunk[i][-overlap:]==chunk[i+1][:overlap]`). overlap>=size/음수→ValueError.
- `chunk_size_comparison(text, sizes, overlap)`: size별 청크 수·평균 길이 표. 결론: 조항 단위 검색엔 200~500자 적합.

### rag_qa (16강)
- 문제 1: `rag_service.answer()`가 이미 `{"answer", "sources"}`(출처 파일명 포함) 반환 → 해답에서 재사용.
- 문제 2: `GRADING_SET`(3문항, PDF 근거 정답) + `grade(answer_fn=None)`. 콤마·단위 정규화로 "10,000원"≈"10000" 매칭. `answer_fn` 주입 가능.
- 채점 정답값(PDF 직접 확인): 로봇청소기 흡입력 **4,000Pa**, 최대 주행 **180분**, 제주 단순변심 반품 왕복 **10,000원**.

## 4. Codex 점검 및 반영

Codex CLI 검수(저강도, `reports/_codex_실습해답_review.txt`): 판정 — rag_console 문제1/2 O, rag_qa 문제1/2 O, embedding 문제1 O·문제2(데모 curate 미흡). 지적 반영:

1. **(실제 버그) rag_qa `grade` 숫자 부분매칭 오탐**: "1800분"이 "180"에, "14000"이 "4000"에 매칭될 수 있었음 → `re.findall(r"\d+")`로 **온전한 숫자 토큰 일치**로 변경. "4,000Pa"/"180분"은 통과, "1800분"/"14000"은 미통과. 회귀 테스트 추가.
2. **embedding 문제2 데모**: 임의 인덱스(reviews[0/1/-1]) → **'배송' 주제 리뷰 2개(유사) vs 무관 리뷰 1개**를 골라 비교하도록 수정(문제 요구 "긍정/무관" 반영).
3. **rag_console overlap=0 엣지**: docstring에 "overlap>0일 때 겹침" 명시. 테스트를 **모든 인접 청크 겹침 + 겹침제거 후 원문복원**까지 검증하도록 강화.
4. **테스트 보강**: embedding 빈docs·k초과 엣지, rag_qa 단위(Pa/분) 매칭·오탐방지, rag_console 원문복원.

## 4. RULE 준수 최종 점검 (Codex 확인)
- 하드코딩 없음: 모델명·경로·가격표·SECRET 전부 config
- 폴백 없음: 키/설정/인프라 실패는 ConfigError/InfraError, 비즈니스 실패만 구조화 관찰

- 검증·리포트: 매 Phase pytest 로그 + 리포트 + history + Codex 2회 리뷰(계획+구현)

## 5. 이월 항목 (실키 스모크 대상)

## 6. 프로덕션 잔여 리스크 (Codex Top 5 반영)
1. 운영 에이전트 경로(`/api/agent/chat`=수동)와 LangChain 병존 → 실키 대조 후 단일화 결정
2. ML은 독립 API(에이전트 미연결) → 필요 시 도구화
3. 로컬 Gemma RAM 5.5GB+ 필요, CPU 추론 느림
4. tiktoken 토큰수는 참고치(Gemma 실토큰 아님), 비용추정은 등록 모델만
5. 레거시 28개 폴더 정리(보존/삭제) 사용자 결정 대기

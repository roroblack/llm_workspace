### RAG QA (HTTP)
```
POST /api/rag/qa {"question":"제주 지역 단순변심 반품의 왕복 배송비는?","top_k":4}
status 200 | 129s
sources: [{환불교환정책.pdf, page:1}, {환불교환정책.pdf, page:2}]
QA_HTTP_OK
```
- 검색(실 임베딩) → PDF 근거 청크 → 답변 생성 → **출처(파일·1-based 페이지) 인용** 전 경로 동작.

### 에이전트 tool-calling (HTTP) — 이월 항목 해소
```
POST /api/agent/chat {"question":"P0001 상품 가격 알려줘","max_steps":2}
steps: [('get_price', {'product_code':'P0001'}, ok=True)]   ← 실제 도구 호출·실행
stopped_by: final_answer | 60s
AGENT_TOOLCALL_OK
```

**실제 버그 발견·수정**: `react.py`가 `tools`만 보내고 **`tool_choice`를 안 보냈다.**
OpenAI SDK는 `tool_choice`를 기본 전송하지 않는데, llama-cpp의 function-calling 핸들러는
이게 있어야 도구 호출이 켜진다. 격리 검증:
```
tool_choice 없음   → tool_calls: False  (모델이 텍스트로만 답변)
tool_choice='auto' → tool_calls: ['get_price'] ✓
```
→ `react.py`에 `tool_choice="auto"` 추가(실 OpenAI에선 기본값이라 무해). 회귀 없음(CI 116/ml 20).
근거: `debug_notes/2026-07-13_2130_에이전트_toolcalling_로컬검증_성공.md`

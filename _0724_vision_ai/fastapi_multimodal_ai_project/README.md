# FastAPI Multimodal AI Studio

FastAPI 기반의 멀티모달 인공지능 서비스입니다.

사용자는 텍스트를 입력하거나 마이크를 통해 음성을 입력할 수 있으며, 음성을 텍스트로 변환(STT)하여 이미지를 생성할 수 있습니다. 또한 이미지를 업로드하면 이미지의 내용을 자연스러운 한국어 문장으로 설명하는 이미지 캡셔닝 기능을 제공합니다.

본 프로젝트는 한국어 입력을 자연스럽게 처리하고, 고품질 이미지 생성과 한국어 이미지 설명을 하나의 웹 서비스에서 제공합니다.

---

# 주요 기능

## 1. 텍스트 기반 이미지 생성

사용자가 입력한 한국어 프롬프트를 이해하여 원하는 이미지를 생성합니다.

예시

- 바닷가를 달리는 빨간 스포츠카
- 우주에서 기타를 연주하는 고양이
- 벚꽃이 피는 산책길
- 미래 도시의 야경

생성된 이미지는 화면에 출력되며 서버에 자동 저장됩니다.

---

## 2. 음성(STT) 기반 이미지 생성

마이크 버튼을 누르면 음성을 녹음합니다.

음성은 STT(Speech To Text)를 이용하여 텍스트로 변환됩니다.

변환된 텍스트는 이미지 생성 프롬프트로 자동 사용되어 이미지를 생성합니다.

처리 과정

```
마이크 입력
      │
      ▼
음성 녹음
      │
      ▼
STT 변환
      │
      ▼
텍스트 프롬프트
      │
      ▼
이미지 생성
```

---

## 3. 이미지 캡셔닝

사용자가 이미지를 업로드하면 AI가 이미지를 분석하여 자연스러운 한국어 문장으로 설명합니다.

예시

```
푸른 잔디 위에서 흰 강아지가 공을 가지고 뛰어놀고 있습니다.
```

캡셔닝 결과는 화면에 출력됩니다.

---

## 4. 한국어 지원

모든 기능은 한국어 사용을 기본으로 설계되었습니다.

- 한국어 프롬프트 입력
- 한국어 음성 입력
- 한국어 이미지 설명 출력

---

## 5. 이미지 저장

생성된 이미지는 자동 저장됩니다.

예시

```
generated_images/

    image_20260731_101501.png

    image_20260731_101540.png
```

# 설치

## 1. 프로젝트 다운로드

```
git clone 프로젝트주소
```

또는 ZIP 파일을 다운로드하여 압축을 해제합니다.

---

## 2. 가상환경 생성

Windows

```
python -m venv .venv
```

Linux

```
python3 -m venv .venv
```

---

## 3. 가상환경 실행

Windows

```
.venv\Scripts\activate
```

Linux

```
source .venv/bin/activate
```

---

## 4. 라이브러리 설치

```
pip install -r requirements.txt
```

---

## 5. 실행

```
python run.py
```

또는

```
uvicorn app.main:app --reload
```

브라우저에서

```
http://127.0.0.1:8000
```

접속합니다.

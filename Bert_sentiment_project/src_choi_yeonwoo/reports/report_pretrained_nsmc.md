# 한국어 감성분석 결과 리포트 ① — 사전학습 NSMC 모델 (빠른 경로)

- 브랜치: `choi_yeonwoo`
- 패키지: `src_choi_yeonwoo/`
- 작성일: 2026-06-30

## 1. 개요
학습 없이 즉시 사용 가능한 한국어 감성분석 모델을 적용했습니다.
NAVER 뉴스 분류 작업물에서 사용하던 **KoELECTRA** 계열의 공개 모델로, 영화 리뷰
감성 코퍼스(NSMC)에 이미 미세조정되어 있어 한국어 리뷰의 긍정/부정을 바로 판별합니다.

| 항목 | 내용 |
|------|------|
| 모델 | `monologg/koelectra-base-finetuned-nsmc` |
| 백본 | KoELECTRA-base v3 (discriminator) |
| 학습 데이터 | NSMC (Naver sentiment movie corpus, 영화 리뷰 긍/부정) |
| 라벨 | 0 = 부정, 1 = 긍정 (positive_index = 1) |
| 최대 토큰 길이 | 64 |
| 실행 장치 | CPU (CUDA 미사용) |
| 최초 로딩 시간 | 약 194초 (모델 다운로드 포함, 이후 캐시되어 빠름) |

## 2. 적용 방법
- `src_choi_yeonwoo/config.py` 의 `DEFAULT_MODEL_NAME` 에 위 모델을 지정.
- `src_choi_yeonwoo/predict.py` 의 `KoreanSentimentPredictor` 가
  - 직접 파인튜닝한 로컬 모델(`models/korean_sentiment/`)이 있으면 그것을,
  - 없으면 위 사전학습 모델을 자동으로 불러옵니다.
- 모델 설정(`id2label`)을 읽어 '긍정' 클래스 인덱스를 자동 판별하므로 라벨 순서가 달라도 안전합니다.

실행:
```bash
python -m src_choi_yeonwoo.predict
# 또는 앱에서: streamlit run app/streamlit_app.py  → 🇰🇷 한국어 영역
```

## 3. 정성 검증 (샘플 6문장)
6개 테스트 문장 모두 사람이 보기에 정답과 일치 — **6/6 정확**. (표본이 적어 정량 평가는 5절 참고)

| 입력 문장 | 예측 | 긍정 확률 | 부정 확률 |
|-----------|------|-----------|-----------|
| 이 영화 정말 재미있어요. 강력 추천합니다. | **긍정** | 0.9580 | 0.0420 |
| 시간 낭비였어요. 정말 별로네요. | **부정** | 0.0028 | 0.9972 |
| 배우 연기는 좋았지만 스토리가 너무 지루했다. | **부정** | 0.0025 | 0.9975 |
| 기대 안 했는데 생각보다 훨씬 좋았어요! | **긍정** | 0.9989 | 0.0011 |
| 음식이 맛없고 서비스도 최악이었습니다. | **부정** | 0.0033 | 0.9967 |
| 가격 대비 만족스러운 제품입니다. | **긍정** | 0.9959 | 0.0041 |

> 영화 리뷰뿐 아니라 음식점·제품 리뷰 같은 일반 도메인 문장에서도 자연스럽게 동작했습니다.
> "배우 연기는 좋았지만 스토리가 너무 지루했다" 처럼 칭찬+비판이 섞인 문장도 전체 부정으로 올바르게 판단했습니다.

## 4. 장단점
- **장점**: 학습 불필요, 즉시 사용, 높은 신뢰도(확률 대부분 0.95↑), NSMC 전체로 학습돼 일반화 우수.
- **단점**: 최초 1회 모델 다운로드(약 400MB) 필요, 라벨이 영화 리뷰 도메인 기준(긍/부정 2분류).
- **결론**: 실습문제의 "한국어 리뷰 입력 → 감성분석 결과 출력" 요구를 바로 충족합니다.

## 5. 정량 평가 — NSMC 공식 테스트셋 5,000개

샘플 6문장은 표본이 적어 정성 확인용입니다. 그래서 **NSMC 공식 테스트셋(50,000개) 중 5,000개**
(긍정 2,484 / 부정 2,516)로 정량 평가했습니다.

| 지표 | 값 |
|------|----|
| 정확도(Accuracy) | **0.9000** |
| 정밀도(Precision) | 0.8912 |
| 재현율(Recall) | 0.9098 |
| F1-score | 0.9004 |
| 커스텀 20문장 정확도 | **20 / 20 (1.0000)** |

혼동행렬 (행=실제, 열=예측):

| 실제 \ 예측 | 부정 | 긍정 |
|-------------|------|------|
| **부정** | 2240 (TN) | 276 (FP) |
| **긍정** | 224 (FN) | 2260 (TP) |

> 5,000개 대규모 표본에서도 90% 정확도로 안정적이며, 다양한 도메인(영화·음식·제품·배송 등)
> 커스텀 20문장은 모두 정확히 분류했습니다.

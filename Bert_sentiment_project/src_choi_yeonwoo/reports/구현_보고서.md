## 1. 요구사항 1 — 복제 후 본인 브랜치로 연결

부모(과제 원본) 레포는 건드리지 않고, 작업 결과는 **본인 레포의 `choi_yeonwoo` 브랜치**로만 올라가도록 원격을 재구성했습니다.

```bash
# 새 작업 브랜치 생성/이동
git checkout -b choi_yeonwoo

# 기존 origin(과제 원본 레포)을 upstream 으로 이름만 변경하여 "보존"(푸시 금지)
git remote rename origin upstream      # upstream = sarastudy1009-svg/Bert_sentiment_project

# 본인 레포를 새 origin 으로 연결
git remote add origin https://github.com/study-ai-skn/Bert_sentiment_project.git
```

결과:

| 원격 이름 | 주소 | 용도 |
|-----------|------|------|
| `origin` | `study-ai-skn/Bert_sentiment_project` | 본인 레포. **여기 `choi_yeonwoo` 로만 푸시** |
| `upstream` | `sarastudy1009-svg/Bert_sentiment_project` | 과제 원본. 보존만 하고 푸시하지 않음 |

> 부모 레포에 영향을 주지 않으면서 본인 레포로만 제출하기 위한 구성입니다.

## 2. 요구사항 2 — 새 패키지 `src_choi_yeonwoo/` (구조 동일)

영어용 `src/` 와 **파일 이름·역할을 1:1로 동일**하게 맞췄습니다. 한국어 처리를 위해 내부 구현만 바꿨습니다.

```
src/ (영어, 기존)            src_choi_yeonwoo/ (한국어, 신규)
├─ config.py                 ├─ config.py        ← 모델명/경로/라벨만 한국어용으로 변경
├─ data_loader.py            ├─ data_loader.py   ← NSMC 자동 다운로드 + 로드 추가
├─ dataset.py                ├─ dataset.py       ← Auto 토크나이저 대응(token_type_ids 처리)
├─ modeling.py               ├─ modeling.py      ← AutoModel* 로 일반화 + 전체학습(strategy 0) 추가
├─ predict.py                ├─ predict.py       ← KoreanSentimentPredictor (긍정 인덱스 자동판별)
├─ train.py                  ├─ train.py         ← NSMC 파인튜닝 + 평가지표 저장
└─ utils.py                  └─ utils.py         ← 동일(시드/장치)
```

### 2-1. 파일별 핵심 수정 내용

**`config.py`** — 영어 BERT 설정을 한국어 감성분석 설정으로 교체
- `DEFAULT_MODEL_NAME` : `bert-base-uncased` → `monologg/koelectra-base-finetuned-nsmc` (한국어 NSMC 감성 모델)
- `BASE_MODEL_NAME` 추가 : 직접 파인튜닝용 백본 `monologg/koelectra-base-v3-discriminator`
- `NSMC_TRAIN/TEST_PATH`, `NSMC_TRAIN/TEST_URL` 추가 : NSMC 데이터 자동 다운로드 경로/주소
- `MODEL_DIR` : `models/bert_sentiment` → `models/korean_sentiment` (영어 모델과 분리 저장)
- `MAX_LEN` : 128 → 64 (영화 리뷰는 짧음)
- `ID_TO_LABEL = {0: "부정", 1: "긍정"}` (NSMC 라벨 규칙)

**`data_loader.py`** — 한국어 데이터 로딩 추가
- `download_nsmc_if_needed()` : NSMC TSV(train/test)가 없으면 공개 저장소에서 자동 다운로드
- `load_nsmc()` : NSMC TSV(`id, document, label`)를 `review/sentiment` 표준 컬럼으로 변환
- `load_sentiment_csv()`, `split_dataset()` : 영어용과 동일 규칙 유지(UTF-8/cp949 자동 대응)

**`dataset.py`** — 토크나이저 일반화
- BERT 전용 `BertTokenizerFast` 대신 **AutoTokenizer 호출 형태**로 변경(`tokenizer(...)`)
- BERT 계열이 쓰는 `token_type_ids` 가 있으면 함께 전달하도록 처리(KoELECTRA/KoBERT 모두 호환)
- 클래스명: `BertSentimentDataset` → `KoreanSentimentDataset`

**`modeling.py`** — 모델 생성 일반화 + 전략 추가
- `BertForSequenceClassification` → **`AutoModelForSequenceClassification`** (KoELECTRA/KoBERT 등 어떤 백본도 지원, `ignore_mismatched_sizes=True` 로 분류 헤드 신규 초기화)
- `apply_fine_tuning_strategy()` 를 모델 구조에 의존하지 않게 재작성(이름에 `classifier` 포함 여부 + 마지막 인코더 레이어 번호를 동적으로 탐지)
- **전략 0(전체 파라미터 풀 파인튜닝)** 추가 — 정확도 최우선용

**`predict.py`** — 한국어 예측 클래스
- `KoreanSentimentPredictor` : 로컬 파인튜닝 모델(`models/korean_sentiment`)이 있으면 그것을, 없으면 사전학습 NSMC 모델을 자동 사용
- `_resolve_positive_index()` : 모델 `config.id2label` 을 읽어 '긍정' 클래스 인덱스를 자동 판별(라벨 순서가 달라도 안전)
- 반환 형식은 영어용 `SentimentPredictor.predict()` 와 **동일한 dict**(`label`, `positive_probability`, `negative_probability`, `model_path`) → 앱에서 동일하게 사용 가능

**`train.py`** — NSMC 직접 파인튜닝
- NSMC 자동 다운로드 → 표본 제한(`--max_samples`, CPU 고려) → train/valid/test 분리 → Trainer 학습 → 테스트 평가 → 모델/토크나이저 저장
- 평가 지표를 `models/korean_sentiment/test_metrics.json` 으로 저장(리포트 활용)

**`utils.py`** — 영어용과 동일(시드 고정, 장치 선택)

   - 상세: [`reports/report_pretrained_nsmc.md`](report_pretrained_nsmc.md)
2. **직접 파인튜닝(느린 경로)** — KoELECTRA 백본을 NSMC 로 직접 학습
   - 상세: [`reports/report_finetuned_nsmc.md`](report_finetuned_nsmc.md)

실행:
```bash
python -m src_choi_yeonwoo.predict                       # 사전학습 모델로 바로 예측
```

## 4. 요구사항 4 — Streamlit 앱 연결

`app/streamlit_app.py` 에서 **영어 입력 필드는 그대로 유지**하고, 그 아래에 **한국어 섹션을 추가**했습니다.

추가/변경한 부분:
- 한국어 패키지 import 추가
  ```python
  from src_choi_yeonwoo.config import MODEL_DIR as KO_MODEL_DIR
  from src_choi_yeonwoo.predict import KoreanSentimentPredictor
  ```
- 한국어 모델 캐싱 로더 추가
  ```python
  @st.cache_resource
  def load_korean_predictor() -> KoreanSentimentPredictor:
      return KoreanSentimentPredictor(model_dir=KO_MODEL_DIR)
  ```
- 결과 출력 공통 함수 `render_result()` 로 영어/한국어 출력 형식 통일
- 화면 구성: `🇺🇸 영어 리뷰 감성분석`(기존 유지) → `st.divider()` → `🇰🇷 한국어 리뷰 감성분석`(신규)
- **한국어 입력은 `input_text` 변수로 받고, '감성분석' 버튼 클릭 시 결과 출력**
  ```python
  input_text = st.text_area("한국어 리뷰 문장", value="이 영화 정말 재미있어요. 강력 추천합니다.", key="ko_text")
  if st.button("감성분석", type="primary", key="ko_button"):
      korean_predictor = load_korean_predictor()
      render_result(korean_predictor.predict(input_text))
  ```
- 영어/한국어 버튼·입력의 `key` 를 분리해 두 섹션이 독립적으로 동작하도록 처리

실행:
```bash
streamlit run app/streamlit_app.py
```
→ 한국어 영역에 리뷰 입력 후 '감성분석' 버튼 클릭 시 **긍정/부정 결과 + 긍정·부정 확률**이 출력됩니다.

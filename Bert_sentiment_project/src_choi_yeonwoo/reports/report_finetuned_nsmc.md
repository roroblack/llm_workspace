# 한국어 감성분석 결과 리포트 ② — NSMC 직접 파인튜닝 (느린 경로)

- 브랜치: `choi_yeonwoo`
- 패키지: `src_choi_yeonwoo/`
- 작성일: 2026-06-30
- 실행 장치: CPU (CUDA 미사용)

## 1. 개요
한국어 사전학습 백본 **KoELECTRA**(`monologg/koelectra-base-v3-discriminator`)에 분류 헤드를 붙여
**NSMC(Naver sentiment movie corpus)** 영화 리뷰 데이터로 직접 파인튜닝했습니다.
NSMC 원본 데이터는 `src_choi_yeonwoo/data_loader.py` 가 공개 저장소에서 자동으로 내려받습니다.

학습된 모델은 `models/korean_sentiment/` 에 저장되며, 앱·예측기는 이 로컬 모델을 **우선** 사용합니다.

## 2. 두 차례 학습 비교 (부분학습 → 전체학습)

CPU 환경에서 두 가지 Fine-tuning 전략을 실험했습니다.

| 구분 | 1차: strategy 3 (부분학습) | 2차: strategy 0 (전체 풀 파인튜닝) |
|------|---------------------------|-----------------------------------|
| 학습 범위 | 마지막 인코더 레이어 + 분류 헤드만 | **전체 파라미터** |
| 학습 가능 파라미터 | 7.68M / 112.9M (6.8%) | 112.9M / 112.9M (100%) |
| 학습 표본 수 | 6,000 | 8,000 |
| Epoch | 1 | 1 |
| max_len | 64 | 64 |
| 학습 시간 | 약 7분 | 약 25분 |
| **테스트 정확도** | 0.7558 | **0.8713** |
| 테스트 정밀도 | 0.7412 | **0.8818** |
| 테스트 재현율 | 0.7774 | **0.8552** |
| **테스트 F1** | 0.7588 | **0.8683** |
| 테스트 Loss | 0.5048 | **0.3327** |
| 샘플 6문장 정확도 | 3 / 6 (긍정 편향) | **6 / 6** |

> **관찰**: 1차(부분학습)는 백본 대부분을 동결해 과소적합되었고, 학습 도메인(영화 리뷰)과 다른
> 일반 문장에서 모두 '긍정'으로 치우치는 편향을 보였습니다(6개 중 3개만 정답).
> 2차(전체 파인튜닝)에서 백본 전체를 학습하자 정확도가 **75.6% → 87.1%** 로 크게 오르고
> 편향도 해소되어 일반 문장 6개를 모두 정확히 분류했습니다.

## 3. 최종 모델(전체 파인튜닝) 샘플 검증
6개 테스트 문장 모두 정답과 일치 — **6/6 정확**.

| 입력 문장 | 예측 | 긍정 확률 | 부정 확률 |
|-----------|------|-----------|-----------|
| 이 영화 정말 재미있어요. 강력 추천합니다. | **긍정** | 0.9558 | 0.0442 |
| 시간 낭비였어요. 정말 별로네요. | **부정** | 0.0497 | 0.9503 |
| 배우 연기는 좋았지만 스토리가 너무 지루했다. | **부정** | 0.0619 | 0.9381 |
| 기대 안 했는데 생각보다 훨씬 좋았어요! | **긍정** | 0.9520 | 0.0480 |

| 가격 대비 만족스러운 제품입니다. | **긍정** | 0.9570 | 0.0430 |

## 4. 정량 평가 — NSMC 공식 테스트셋 5,000개

샘플 6문장은 표본이 적어, **NSMC 공식 테스트셋(50,000개) 중 5,000개**(긍정 2,484 / 부정 2,516)로
독립 평가했습니다. (학습에 쓰지 않은 공식 테스트 데이터)

| 지표 | 직접 파인튜닝(풀) | 참고: 사전학습 모델 |
|------|-------------------|---------------------|
| 정확도(Accuracy) | **0.8432** | 0.9000 |
| 정밀도(Precision) | 0.8608 | 0.8912 |
| 재현율(Recall) | 0.8164 | 0.9098 |
| F1-score | 0.8380 | 0.9004 |
| 커스텀 20문장 | **20/20** | 20/20 |

직접 파인튜닝 모델 혼동행렬 (행=실제, 열=예측):

| 실제 \ 예측 | 부정 | 긍정 |
|-------------|------|------|
| **부정** | 2188 (TN) | 328 (FP) |
| **긍정** | 456 (FN) | 2028 (TP) |

> 학습 중 분리한 소규모 테스트(1,600개)에서는 87.1%였지만, 더 큰 독립 표본(5,000개)에서는
> **84.3%** 로 나왔습니다 — 이것이 일반화 성능에 더 가까운 값입니다. 8,000개 표본·1 epoch 만 학습한
> 결과로, 표본/epoch 를 늘리면 사전학습 모델(90%)에 더 근접합니다. 다양한 도메인 커스텀 20문장은 모두 정답.

## 5. 재현 방법
```bash
# (1차) 부분학습 — 빠르지만 정확도 낮음
python -m src_choi_yeonwoo.train --epochs 1 --strategy 3 --max_samples 6000

# (2차) 전체 풀 파인튜닝 — 권장
python -m src_choi_yeonwoo.train --epochs 1 --strategy 0 --max_samples 8000
```
- 평가 지표 원본: `models/korean_sentiment/test_metrics.json`(학습 분리셋), [`_eval_full.json`](_eval_full.json)(NSMC 5,000)
- 샘플 예측 원본: [`_finetuned_eval.json`](_finetuned_eval.json) (최종), [`_finetuned_eval_strategy3.json`](_finetuned_eval_strategy3.json) (1차)

## 6. 사전학습 모델과의 비교 및 결론

| 항목 | 사전학습 NSMC 모델 | 직접 파인튜닝 (전체학습) |
|------|--------------------|--------------------------|
| 모델 | `monologg/koelectra-base-finetuned-nsmc` | KoELECTRA + 자체 학습 |
| 학습 데이터 | NSMC 전체(15만) | NSMC 8,000 표본 |
| NSMC 5,000 정확도 | **0.9000** | 0.8432 |
| 커스텀 20문장 | 20/20 | 20/20 |
| 학습 필요 | 불필요(즉시 사용) | 필요(CPU 약 25분) |
| 용도 | 데모·실사용 권장 | 학습 과정 이해·커스텀 데이터 확장 |

- **결론**: 두 방식 모두 한국어 리뷰 긍정/부정을 정확히 분류합니다(커스텀 20문장 모두 정답).
  대규모 정량 평가에서는 데이터 전체(15만)로 학습된 **사전학습 모델(90%)** 이 8,000개만 학습한
  직접 파인튜닝(84.3%)보다 높았습니다. 직접 파인튜닝은 표본/epoch 를 늘리면 더 향상됩니다.
- 앱은 `models/korean_sentiment/` 의 직접 파인튜닝 모델을 우선 사용하며,
  해당 폴더를 비우면 자동으로 사전학습 모델(90%)로 동작합니다.

 **FastAPI + PyCharm + RunPod 연계 파인튜닝 모델 성능 평가 프로젝트**


## 포함된 기능

* 로컬 PyCharm용 `mock` 추론 모드
* RunPod GPU용 Hugging Face `transformers` 추론 모드
* Base 모델과 Fine-tuned 모델 단일 질문 비교
* 평가 데이터 전체 자동 실행
* Exact Match 평가
* ROUGE-1, ROUGE-2, ROUGE-L 평가
* 선택적 BERTScore 평가
* JSON 출력 형식 준수율 평가
* 평균·중앙값 응답 시간 측정
* 초당 생성 토큰 수 측정
* Base 모델과 Fine-tuned 모델 변화량 비교
* JSONL 예측 결과 및 JSON 평가 보고서 저장
* 블라인드 사람 평가용 CSV 생성
* LoRA·QLoRA Adapter 병합 스크립트
* FastAPI 웹 UI
* Swagger API 테스트
* Pytest 자동 테스트
* PyCharm SSH Interpreter 및 SFTP 연계 설명
* RunPod 설치·실행 절차

## 로컬 PyCharm 실행

```powershell
python -m venv .venv
.\.venv\Scripts\activate

python -m pip install --upgrade pip
pip install -r requirements-local.txt

copy .env.example .env
python run_local.py
```

접속 주소:

```text
웹 화면
http://127.0.0.1:8000

Swagger
http://127.0.0.1:8000/docs

상태 확인 API
http://127.0.0.1:8000/api/system/health
```

로컬에서는 `.env`의 다음 설정을 유지합니다.

```env
INFERENCE_BACKEND=mock
```

따라서 GPU나 모델 다운로드 없이 FastAPI, 웹 화면, 평가 API 흐름을 먼저 확인할 수 있습니다.

## RunPod 실행

RunPod에서는 프로젝트를 다음 경로에 업로드하는 구성을 기준으로 작성했습니다.

```text
/workspace/fastapi_runpod_llm_evaluation
```

SSH 접속 후:

```bash
cd /workspace/fastapi_runpod_llm_evaluation

python -m venv .venv
source .venv/bin/activate

python -m pip install --upgrade pip
pip install -r requirements-runpod.txt

cp .env.example .env
```

`.env` 설정:

```env
INFERENCE_BACKEND=transformers

BASE_MODEL_PATH=Qwen/Qwen2.5-0.5B-Instruct

FINE_TUNED_MODEL_PATH=/workspace/models/merged_model

DEVICE_MAP=auto
TORCH_DTYPE=auto
LOAD_IN_4BIT=false

MAX_NEW_TOKENS=256
HOST=0.0.0.0
PORT=8000
```

서버 실행:

```bash
chmod +x run_runpod.sh
./run_runpod.sh
```

또는:

```bash
uvicorn app.main:app --host 0.0.0.0 --port 8000 --workers 1
```

FastAPI 애플리케이션은 Uvicorn과 같은 ASGI 서버로 실행할 수 있으며, RunPod는 SSH 접속과 Pod 서비스 포트 노출 기능을 제공합니다. ([FastAPI][1])

## 평가 실행

Base 모델 평가:

```bash
python scripts/generate_predictions.py \
  --model-kind base \
  --input-file data/evaluation.jsonl \
  --output-file outputs/base_predictions.jsonl
```

Fine-tuned 모델 평가:

```bash
python scripts/generate_predictions.py \
  --model-kind fine_tuned \
  --input-file data/evaluation.jsonl \
  --output-file outputs/fine_tuned_predictions.jsonl
```

두 모델 전체 비교:

```bash
python scripts/run_full_evaluation.py
```

블라인드 평가 CSV 생성:

```bash
python scripts/create_blind_review.py
```

## LoRA·QLoRA Adapter 병합

```bash
python scripts/merge_lora_adapter.py \
  --base-model Qwen/Qwen2.5-0.5B-Instruct \
  --adapter-path /workspace/models/dpo_adapter \
  --output-path /workspace/models/merged_model
```

PEFT의 `merge_and_unload()`는 LoRA Adapter 가중치를 기반 모델에 병합하여 독립 모델 형태로 만들 때 사용할 수 있습니다. ([Hugging Face][2])

## 검증 결과

프로젝트에 포함된 Python 파일 16개의 문법 컴파일 검사를 수행했으며 문법 오류는 발견되지 않았습니다.

실제 RunPod GPU 모델 다운로드와 추론 실행은 이 환경에서 수행하지 못했으므로, RunPod에서는 먼저 다음 순서로 확인하는 것이 안전합니다.

```bash
python -c "import torch; print(torch.__version__); print(torch.cuda.is_available()); print(torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'GPU 없음')"

pytest -q

uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Transformers의 `Trainer`는 PyTorch 모델의 학습 및 평가 루프를 제공하며, 평가용 데이터와 지표 계산 함수를 연결하는 방식으로 확장할 수 있습니다.

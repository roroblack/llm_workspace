[Research Agent FastAPI 최종 프로젝트 다운로드]

## 적용된 전체 구조

```text
사용자
  ↓
FastAPI 웹 UI / REST API / Swagger
  ↓
LangGraph StateGraph
  ├─ ReAct
  │    └─ 질문 분석 → 도구 선택 → 실행 → 관찰 → 최종 답변
  │
  ├─ RAG
  │    └─ PDF·CSV → 청크 분할 → 임베딩 → FAISS → 근거 검색
  │
  ├─ A2A
  │    ├─ web-research-agent
  │    ├─ knowledge-agent
  │    ├─ deep-research-agent
  │    ├─ cross-check-agent
  │    └─ data-analyst-agent
  │
  └─ MCP
       ├─ 웹 검색 도구
       ├─ 내부 지식 검색 도구
       ├─ 경쟁사 데이터 도구
       └─ 내부 매출 데이터 도구
  ↓
OpenAI 또는 Gemini
  ↓
DuckDuckGo / FAISS / data.zip / reports
```

ReAct 구현은 LangChain 1.x의 표준 방식인 `create_agent`를 사용했습니다. 
현재 공식 문서에서도 이전 `create_react_agent` 대신 `create_agent` 사용을 권장하며, 
LangChain 에이전트 자체도 LangGraph 위에서 실행됩니다. ([Docs by LangChain][1])

전체 실행 흐름은 공유 상태를 읽고 수정하는 LangGraph `StateGraph`로 구성했습니다. ([LangChain Reference Docs][2])

MCP 서버는 공식 Python SDK의 `FastMCP` 기반이며 `stdio` 방식으로 독립 실행할 수 있습니다. ([MCP Python SDK][3])

A2A 계층에는 전문 에이전트 카드와 메시지 위임 API를 구현했습니다. 
A2A의 Agent Card는 에이전트의 기능과 접속 정보를 공개하는 표준 JSON 문서입니다. ([A2A Protocol][4])

## 기능

* 검색 없는 LLM 응답
* DuckDuckGo 최신 정보 검색
* 검색 실패 시 LLM 폴백
* 심층 조사와 하위 질의 분해
* 검색 결과 교차 검증
* 경쟁사 CSV 리포트
* 월별 매출·상품 데이터 리포트
* 마크다운 보고서 저장
* 실습문제 1 경쟁사 분석
* 실습문제 2 다중 하위 질의 조사
* OpenAI와 Gemini 선택 실행

## LangGraph 자동 분기

```text
mcp: 로 시작
→ MCP 도구 직접 실행

내부 문서 / PDF / 근거 / RAG
→ RAG
→ knowledge-agent

경쟁사 / 매출 / CSV / 내부 데이터
→ A2A
→ data-analyst-agent

교차 검증 / 사실 확인
→ A2A
→ cross-check-agent

심층 조사 / 다각도 조사
→ A2A
→ deep-research-agent

최신 / 시장 동향 / 뉴스
→ A2A
→ web-research-agent

그 밖의 복합 질문
→ ReAct
→ 필요한 웹·RAG·CSV 도구 자율 선택
```

## 주요 API

| 메서드  | 경로                                    | 기능                 |
| ---- | ------------------------------------- | ------------------ |
| GET  | `/`                                   | 통합 웹 UI            |
| GET  | `/docs`                               | Swagger            |
| GET  | `/redoc`                              | ReDoc              |
| GET  | `/api/v1/health`                      | 서버와 API 키 상태       |
| POST | `/api/v1/chat`                        | LangGraph 전체 워크플로우 |
| POST | `/api/v1/tools/call`                  | MCP 호환 도구 직접 실행    |
| GET  | `/api/v1/a2a/agents`                  | 전문 에이전트 카드         |
| GET  | `/api/v1/.well-known/agent-card.json` | 통합 A2A 카드          |
| POST | `/api/v1/a2a/message`                 | 전문 에이전트 직접 호출      |
| GET  | `/api/v1/data/files`                  | 전체 데이터 파일 확인       |
| POST | `/api/v1/rag/reset`                   | FAISS 캐시 초기화       |
| GET  | `/api/v1/exercises`                   | 실습문제 실행 요청 예시      |
| GET  | `/api/v1/reports/{filename}`          | 보고서 다운로드           |

## 실행 방법

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1

python -m pip install --upgrade pip setuptools wheel
pip install -r requirements.txt

Copy-Item .env.example .env
```

`.env` 파일에 API 키를 입력합니다.

```dotenv
OPENAI_API_KEY=실제_OpenAI_API_KEY
OPENAI_MODEL=gpt-4o-mini
OPENAI_EMBED_MODEL=text-embedding-3-small

GOOGLE_API_KEY=실제_Google_API_KEY
GEMINI_MODEL=gemini-2.5-flash
GEMINI_EMBED_MODEL=models/gemini-embedding-001
```

PyCharm에서 `run.py`를 실행하거나 다음 명령을 사용합니다.

```powershell
python run.py
```

접속 주소:

```text
웹 UI   : http://127.0.0.1:8000
Swagger : http://127.0.0.1:8000/docs
ReDoc   : http://127.0.0.1:8000/redoc
```

독립 MCP 서버는 다음과 같이 실행합니다.

```powershell
python -m app.mcp_server.server
```

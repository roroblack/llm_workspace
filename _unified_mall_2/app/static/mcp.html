🔌 MCP 연동

이 앱이 MCP 클라이언트로서 자체 MCP 서버(stdio subprocess)를 호출 — REST와 동일 유스케이스 경유

1. 등록된 MCP 도구 목록

POST /api/mcp/tools — 커머스 5 + RAG 2 + ML 3 = 10개 고정.

2. 도구 호출 — get_price (임베딩 불필요)

POST /api/mcp/call — 도구마다 새 subprocess를 띄우는 구조라 첫 호출은 ~수 초~수십 초 걸릴 수 있습니다(학습용 시연 구조, 운영 구조 아님). 결과는 REST GET /api/products/{code}와 같은 commerce_tools 함수를 공유해 항상 동일합니다.
